DeepTeam's own engine on your chatbot: RedTeamer, attack simulation, frameworks, guardrails and the YAML CLI.

Red team with DeepTeam

Runs DeepTeam's RedTeamer.red_team(): DeepTeam simulates attacks for each vulnerability type with the judge, sends them to the chatbot through a model_callback, and scores every reply with its own metrics (0 = vulnerable, 1 = resisted) and a CVSS score. Each attack costs judge calls and chatbot messages.

Runs & risk assessment

YAML / CLI

Download this chatbot as a DeepTeam project and run DeepTeam's own CLI in CI: deepteam run config.yaml. The zip holds config.yaml (models, target callback, system config, the vulnerabilities and attacks ticked under Red team), the callback that calls the chatbot, and a README. Header values (cookies, keys) are never exported; set them in LLM_EVAL_HEADERS.
