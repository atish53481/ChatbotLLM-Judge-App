Chatbot instructions (Prompt Alignment)

Every security probe is also sent in these disguises; results show which disguise gets through. Each enhancer adds one chatbot call per probe.

A/B test two chatbots

Both chatbots answer the selected chatbot's goldens; the judge picks the better reply. Every case is judged twice with the order swapped, and a reply only wins when it wins both times (position bias counts as a tie).

Red-team coverage

The latest run of every adversarial metric, by risk category and OWASP Top 10 for LLM Applications (2025). Untested is not the same as safe.

Simulate a user

The judge plays the user and reacts to what the chatbot actually says, until the goal is reached or the turn limit. One judge call per turn, plus the metrics you tick.

Calibrate the judge

Score a few cases yourself. You see how often the judge agrees with you, and with “Give the judge my calibration labels” (Run options) your scores become examples in G-Eval prompts.

Export to CI

A zip with a pytest suite (tests/evals) and a GitHub Actions workflow that runs these metrics on this chatbot's goldens on every pull request. Header values such as cookies and API keys are never exported; CI reads them from a secret.
